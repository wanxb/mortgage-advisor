## 2. 产品背景

当前市面上的房贷计算器大多可以完成基础月供计算，但存在几个问题：

1. 页面功能分散，用户需要在不同工具之间切换。
2. 提前还款计算不够直观，尤其是“缩短年限”和“减少月供”的差异展示不清晰。
3. 对组合贷支持不够友好，商贷与公积金贷的拆分、合并、提前还款分配不够清楚。
4. 利率变动、LPR 加点、存量房贷利率调整等场景缺少简单明了的对比。
5. 大部分工具只给结果，不给清晰的年度/月份还款明细和方案对比。

本产品希望以简洁操作为前提，将房贷计算、还款明细、提前还款、利率调整、方案对比等能力整合到一个页面中，帮助用户快速做出房贷相关决策。

## 3. 产品目标

### 3.1 核心目标

让用户通过少量输入，快速得到以下答案：

1. 我的房贷每月要还多少钱？
2. 整个贷款周期总利息是多少？
3. 每年、每月分别还了多少本金和利息？
4. 提前还款能省多少钱？
5. 提前还款选择“减少年限”和“减少月供”哪个更合适？
6. 利率调整后，月供和总利息会变化多少？
7. 组合贷中商贷和公积金贷分别承担多少？
8. 我当前收入是否能承受对应月供？

### 3.2 产品原则

1. **功能完整，但页面简洁。**
2. **优先展示用户最关心的结果。**
3. **复杂参数默认收起，高级用户可展开。**
4. **所有计算结果都要能追溯到月度明细。**
5. **提前还款和利率调整必须提供前后对比。**
6. **不强制登录，不制造使用门槛。**

## 4. 目标用户

### 4.1 买房前用户

用户特征：

- 准备购房；
- 需要估算贷款额度、月供、总利息；
- 关心月供压力和预算上限。

核心需求：

- 贷款金额测算；
- 月供测算；
- 可承受房价反推；
- 商贷、公积金贷、组合贷对比。

### 4.2 已有房贷用户

用户特征：

- 已经有存量房贷；
- 关心提前还款是否划算；
- 关心利率下降后的月供变化。

核心需求：

- 已还多少期、剩余本金测算；
- 部分提前还款测算；
- 一次性结清测算；
- 减少年限和减少月供对比；
- 利率调整前后对比。

### 4.3 家庭财务决策用户

用户特征：

- 需要和家人讨论还款方案；
- 关注现金流安全；
- 想比较提前还款、保留现金、投资理财之间的取舍。

核心需求：

- 多方案对比；
- 月供收入比评估；
- 导出或分享结果。

## 6. 页面结构设计

### 6.1 整体页面结构

采用单页工具设计，避免复杂导航。

页面从上到下分为五部分：

1. 顶部标题区；
2. 贷款参数输入区；
3. 计算结果总览区；
4. 功能 Tab 区；
5. 底部说明区。

页面结构示意：

```text
房贷计算器

[贷款类型] [还款方式] [贷款金额] [贷款年限] [贷款利率]

Tab：
- 还款明细

- 利率调整
- 方案对比
- 预算反推
```

## 7. 功能需求详情

# 7.1 基础房贷计算

## 7.1.1 功能说明

用户输入贷款类型、贷款金额、贷款年限、贷款利率、还款方式后，系统自动计算月供、总利息、总还款金额，并生成完整还款计划。

## 7.1.2 贷款类型

| 类型 | 说明 |
|---|---|
| 商业贷款 | 单独计算商业贷款 |
| 公积金贷款 | 单独计算公积金贷款 |
| 组合贷款 | 商业贷款 + 公积金贷款合并计算 |

## 7.1.3 还款方式

| 还款方式 | 说明 |
|---|---|
| 等额本息 | 每月还款金额基本相同 |
| 等额本金 | 每月偿还固定本金，月供逐月减少 |

## 7.1.4 输入字段

### 商业贷款 / 公积金贷款

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| 贷款类型 | 枚举 | 是 | 商业贷款 | 商贷/公积金/组合贷 |
| 贷款金额 | 数字 | 是 | 100 | 单位：万元 |
| 贷款年限 | 数字/枚举 | 是 | 30 | 单位：年 |
| 年利率 | 数字 | 是 | 空 | 单位：% |
| 还款方式 | 枚举 | 是 | 等额本息 | 等额本息/等额本金 |
| 放款日期 | 日期 | 否 | 当前月份 | 用于生成还款计划 |
| 首次还款日期 | 日期 | 否 | 放款后次月 | 可自动生成 |

### 组合贷款

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| 商贷金额 | 数字 | 是 | 空 | 单位：万元 |
| 商贷年限 | 数字 | 是 | 30 | 单位：年 |
| 商贷利率 | 数字 | 是 | 空 | 单位：% |
| 公积金贷款金额 | 数字 | 是 | 空 | 单位：万元 |
| 公积金贷款年限 | 数字 | 是 | 30 | 单位：年 |
| 公积金贷款利率 | 数字 | 是 | 空 | 单位：% |
| 还款方式 | 枚举 | 是 | 等额本息 | V1 默认商贷与公积金贷使用同一还款方式 |

## 7.1.5 输出结果

| 字段 | 说明 |
|---|---|
| 月供 | 等额本息显示固定月供，等额本金显示首月月供 |
| 每月递减 | 仅等额本金展示 |
| 贷款总额 | 本金总额 |
| 总利息 | 全周期利息 |
| 总还款额 | 本金 + 利息 |
| 总期数 | 年限 × 12 |
| 最后还款日期 | 根据首次还款日期和期数计算 |

# 7.2 还款明细

## 7.2.1 功能说明

系统根据贷款计划生成完整的月度还款明细，并按照年份汇总，方便用户查看每年还款情况。

## 7.2.2 月度明细字段

| 字段 | 说明 |
|---|---|
| 期数 | 第 1 期、第 2 期等 |
| 还款日期 | 每期还款日期 |
| 月供 | 当期还款总额 |
| 本金 | 当期偿还本金 |
| 利息 | 当期偿还利息 |
| 剩余本金 | 当期还款后的剩余本金 |
| 累计已还本金 | 截止当期累计已还本金 |
| 累计已还利息 | 截止当期累计已还利息 |

## 7.2.3 年度汇总字段

| 字段 | 说明 |
|---|---|
| 年份 | 例如 2026 |
| 年度还款总额 | 该年度所有月供合计 |
| 年度本金 | 该年度偿还本金合计 |
| 年度利息 | 该年度偿还利息合计 |
| 年末剩余本金 | 该年度最后一期后的剩余本金 |

## 7.2.4 展示规则

1. 默认展示年度汇总。
2. 用户可点击某一年展开该年的月度明细。
3. 月度明细支持表格滚动，不默认全部展开。
4. 金额展示保留两位小数，也可在页面上按整数显示。

# 7.3 提前还款

## 7.3.1 功能说明

用户可以基于当前贷款计划，设置提前还款时间和金额，系统计算提前还款后的新还款计划，并与原计划进行对比。

## 7.3.2 提前还款类型

| 类型 | V1 是否支持 | 说明 |
|---|---|---|
| 部分提前还款 | 是 | 还一部分本金 |
| 一次性结清 | V2 | 还清全部剩余本金 |
| 多次提前还款 | V3 | 支持多个提前还款节点 |

## 7.3.3 部分提前还款输入字段

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| 提前还款日期 | 日期/月 | 是 | 当前月份 | 选择在哪一期后提前还款 |
| 提前还款金额 | 数字 | 是 | 空 | 单位：万元 |
| 处理方式 | 枚举 | 是 | 减少年限 | 减少年限/减少月供 |
| 是否包含当月月供 | 布尔 | 否 | 是 | 提前还款当月是否正常还款 |
| 违约金/手续费 | 数字 | 否 | 0 | 单位：元 |

## 7.3.4 处理方式

### A. 减少年限，月供基本不变

逻辑：

1. 用户在某一期正常还款后，额外偿还一笔本金。
2. 剩余本金减少。
3. 保持原月供尽量不变。
4. 重新计算剩余还款期数。
5. 新贷款期限缩短。

适用场景：

- 用户现金流压力不大；
- 希望尽量减少总利息；
- 希望尽快还清贷款。

### B. 减少月供，期限不变

逻辑：

1. 用户在某一期正常还款后，额外偿还一笔本金。
2. 剩余本金减少。
3. 剩余还款期数保持不变。
4. 重新计算新的月供。
5. 月供下降，但节省利息通常少于缩短年限方案。

适用场景：

- 用户希望降低每月压力；
- 家庭现金流紧张；
- 对尽快结清贷款没有强需求。

## 7.3.5 提前还款输出字段

| 字段 | 说明 |
|---|---|
| 提前还款前剩余本金 | 还款节点前的剩余本金 |
| 提前还款金额 | 用户输入金额 |
| 提前还款后剩余本金 | 扣减后的本金 |
| 原剩余期数 | 提前还款前还剩多少期 |
| 新剩余期数 | 提前还款后还剩多少期 |
| 原月供 | 当前计划月供 |
| 新月供 | 提前还款后的月供 |
| 原剩余利息 | 不提前还款情况下未来还要支付的利息 |
| 新剩余利息 | 提前还款后未来还要支付的利息 |
| 节省利息 | 原剩余利息 - 新剩余利息 - 违约金 |
| 原最后还款日 | 原计划结束日期 |
| 新最后还款日 | 新计划结束日期 |

## 7.3.6 提前还款对比展示

| 指标 | 当前方案 | 提前还款后 | 差额 |
|---|---:|---:|---:|
| 剩余本金 | xxx | xxx | xxx |
| 月供 | xxx | xxx | xxx |
| 剩余期数 | xxx | xxx | xxx |
| 剩余利息 | xxx | xxx | xxx |
| 总还款额 | xxx | xxx | xxx |
| 最后还款日 | xxx | xxx | xxx |

## 7.3.7 结果提示文案

示例：

```text
选择“缩短年限”后，预计可节省利息 62,000 元，贷款可提前 3 年 4 个月还清。

```

# 7.4 利率调整测算

## 7.4.1 功能说明

用户可以输入当前利率和新利率，系统重新计算剩余还款计划，并展示利率调整前后的月供、总利息和明细变化。

## 7.4.2 输入字段

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| 当前利率 | 数字 | 是 | 原贷款利率 | 单位：% |
| 新利率 | 数字 | 是 | 空 | 单位：% |
| 调整生效日期 | 日期/月 | 是 | 当前月份 | 从哪一期开始使用新利率 |
| 剩余本金 | 自动 | 是 | 系统计算 | 根据生效日期自动获取 |
| 剩余期数 | 自动 | 是 | 系统计算 | 根据生效日期自动获取 |

## 7.4.3 利率输入方式

V1：

| 输入方式 | 说明 |
|---|---|
| 手动输入利率 | 用户直接输入年化利率 |

V2：

| 输入方式 | 说明 |
|---|---|
| LPR + BP | 例如 LPR 3.50% + 20BP = 3.70% |
| LPR - BP | 例如 LPR 3.50% - 30BP = 3.20% |

## 7.4.4 输出字段

| 字段 | 说明 |
|---|---|
| 原月供 | 利率调整前月供 |
| 新月供 | 利率调整后月供 |
| 每月减少/增加 | 新旧月供差额 |
| 原剩余利息 | 不调整利率时剩余利息 |
| 新剩余利息 | 调整利率后剩余利息 |
| 节省/增加利息 | 新旧利息差额 |
| 新还款明细 | 使用新利率生成的新计划 |

# 7.5 组合贷款

## 7.5.1 功能说明

组合贷由商业贷款和公积金贷款两部分组成。系统需要分别计算两部分还款计划，再按月份合并展示。

## 7.5.2 计算规则

```text
商贷单独生成还款计划
公积金贷单独生成还款计划
按月份合并：
总月供 = 商贷月供 + 公积金月供
总本金 = 商贷本金 + 公积金本金
总利息 = 商贷利息 + 公积金利息
总剩余本金 = 商贷剩余本金 + 公积金剩余本金
```

## 7.5.3 组合贷输出字段

| 字段 | 说明 |
|---|---|
| 商贷月供 | 商业贷款部分月供 |
| 公积金月供 | 公积金贷款部分月供 |
| 合计月供 | 商贷月供 + 公积金月供 |
| 商贷总利息 | 商贷全周期利息 |
| 公积金总利息 | 公积金全周期利息 |
| 合计总利息 | 两部分利息合计 |
| 商贷剩余本金 | 商贷部分剩余本金 |
| 公积金剩余本金 | 公积金部分剩余本金 |
| 合计剩余本金 | 两部分剩余本金合计 |

## 7.5.4 组合贷提前还款规则

V1：

- 默认按用户选择整体提前还款，优先还商贷。

V2：

支持以下方式：

| 方式 | 说明 |
|---|---|
| 只还商贷 | 提前还款金额全部用于商业贷款 |
| 只还公积金贷 | 提前还款金额全部用于公积金贷款 |
| 按比例还款 | 按剩余本金比例分配 |
| 自定义分配 | 用户手动填写商贷、公积金分别提前还多少 |

# 7.6 方案对比

## 7.6.1 功能说明

用户可以在当前方案基础上生成不同调整方案，并横向比较结果。

## 7.6.2 默认方案

| 方案 | 说明 |
|---|---|
| 原始方案 | 不提前还款，不调整利率 |
| 提前还款-缩短年限 | 部分提前还款后缩短年限 |
| 提前还款-减少月供 | 部分提前还款后减少月供 |
| 利率调整方案 | 使用新利率重新计算 |

## 7.6.3 对比字段

| 字段 | 说明 |
|---|---|
| 月供 | 每月还款金额 |
| 剩余期数 | 还需要还多少期 |
| 剩余本金 | 当前剩余本金 |
| 剩余利息 | 未来还需要支付的利息 |
| 总还款额 | 剩余本金 + 剩余利息 |
| 节省利息 | 相比原方案节省金额 |
| 结束日期 | 最后一笔还款日期 |
| 现金流压力 | 月供收入比结果 |

# 7.7 买房预算反推

## 7.7.1 功能说明

用户输入可接受月供、贷款年限、贷款利率和首付比例，系统反推可承受贷款金额和总房价。

## 7.7.2 输入字段

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| 可承受月供 | 数字 | 是 | 空 | 单位：元 |
| 贷款年限 | 数字 | 是 | 30 | 单位：年 |
| 年利率 | 数字 | 是 | 空 | 单位：% |
| 还款方式 | 枚举 | 是 | 等额本息 | V1 优先支持等额本息 |
| 首付比例 | 数字 | 否 | 30 | 单位：% |

## 7.7.3 输出字段

| 字段 | 说明 |
|---|---|
| 可贷款金额 | 根据月供反推贷款本金 |
| 预计总房价 | 可贷款金额 / 贷款比例 |
| 预计首付金额 | 总房价 × 首付比例 |
| 总利息 | 根据反推贷款金额计算 |
| 总还款额 | 贷款本金 + 总利息 |

# 7.8 月供压力评估

## 7.8.1 功能说明

用户输入家庭月收入，系统计算月供收入比，并给出压力等级。

## 7.8.2 输入字段

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| 家庭月收入 | 数字 | 否 | 空 | 单位：元 |
| 当前月供 | 自动 | 是 | 系统计算 | 由贷款方案生成 |

## 7.8.3 计算规则

```text
月供收入比 = 月供 / 家庭月收入 × 100%
```

## 7.8.4 压力等级

| 月供收入比 | 评价 |
|---|---|
| ≤ 30% | 压力较低 |
| 30% - 40% | 压力适中 |
| 40% - 50% | 压力偏高 |
| > 50% | 风险较高 |

## 9. 核心计算逻辑

# 9.1 等额本息

## 9.1.1 公式

```text
月利率 = 年利率 / 12
总期数 = 贷款年限 × 12

每月月供 = 本金 × 月利率 × (1 + 月利率)^总期数 / ((1 + 月利率)^总期数 - 1)
```

## 9.1.2 每期拆分

```text
当月利息 = 剩余本金 × 月利率
当月本金 = 月供 - 当月利息
剩余本金 = 上期剩余本金 - 当月本金
```

# 9.2 等额本金

## 9.2.1 公式

```text
每月本金 = 贷款本金 / 总期数
当月利息 = 剩余本金 × 月利率
当月月供 = 每月本金 + 当月利息
```

## 9.2.2 每月递减额

```text
每月递减额 = 每月本金 × 月利率
```

# 9.3 提前还款后减少月供

```text
提前还款后剩余本金 = 当前剩余本金 - 提前还款金额
剩余期数不变
按照新的剩余本金、剩余期数和原利率重新计算月供
```

# 9.4 提前还款后缩短年限

```text
提前还款后剩余本金 = 当前剩余本金 - 提前还款金额
尽量保持原月供不变
反推需要多少期还清
生成新的还款计划
```

# 9.5 利率调整

```text
在调整生效日前，使用原还款计划
在调整生效日后，取当前剩余本金和剩余期数
使用新利率重新生成后续还款计划
```

## 11. 非功能需求

### 11.1 性能

1. 普通 30 年贷款共 360 期，前端计算应在 100ms 内完成。
2. 多方案计算应在 500ms 内完成。
3. 表格超过 360 行时仍应保持滚动流畅。

### 11.2 准确性

1. 金额计算应避免浮点数误差。
2. 建议内部以“分”为单位计算，展示时转换为“元”。
3. 最后一期需要校正剩余本金，避免出现 -0.01 等情况。
4. 所有明细合计必须与总览结果一致。

### 11.3 兼容性

1. 支持 Chrome、Edge、Safari 主流浏览器。
2. 支持 PC 与移动端自适应。
3. 不依赖浏览器本地数据库即可完成计算。

### 11.4 隐私

1. V1 不上传用户输入数据。
2. 所有计算在本地浏览器完成。
3. 不要求手机号、身份证、银行卡等敏感信息。
4. 分享链接只包含用户主动生成的计算参数。

## 12. 边界情况与校验规则

| 场景 | 处理规则 |
|---|---|
| 贷款金额为空 | 提示“请输入贷款金额” |
| 利率为空 | 提示“请输入贷款利率” |
| 年限为空 | 提示“请选择贷款年限” |
| 提前还款金额大于剩余本金 | 提示“提前还款金额不能超过剩余本金” |
| 提前还款日期早于首次还款日期 | 提示“提前还款日期不能早于首次还款日期” |
| 利率为 0 | 支持，但需使用无息贷款特殊公式 |
| 年限超过 30 年 | 可提示“请确认贷款年限是否正确” |
| 组合贷某一项金额为 0 | 可自动退化为单一贷款 |
| 最后一期剩余本金小于 0 | 自动校正为 0 |

## 15. 验收标准

### 15.1 基础计算验收

1. 输入商业贷款金额、年限、利率后，可以正确生成月供、总利息、总还款额。
2. 等额本息和等额本金结果明显区分。
3. 月度还款明细中，每期本金、利息、剩余本金准确。
4. 年度汇总金额与月度明细合计一致。
5. 组合贷结果等于商贷和公积金贷分别计算后的合计。

### 15.2 提前还款验收

1. 支持选择提前还款日期和提前还款金额。
2. 支持“减少年限”和“减少月供”。
3. 提前还款后可以生成新的还款计划。
4. 可以展示原方案与新方案的差异。
5. 节省利息计算正确。

### 15.3 利率调整验收

1. 支持输入新利率。
2. 可以从指定月份开始重新计算剩余计划。
3. 可以展示利率调整前后月供差异。
4. 可以展示利率调整前后剩余利息差异。

### 15.4 页面体验验收

1. 页面打开后核心输入项清晰。
2. 用户不需要登录即可使用。
3. 移动端可以正常输入和查看结果。
4. 明细表格不会撑乱页面。
5. 结果文案清晰，不只展示数字。

## 18. 风险与注意事项

1. 不同银行提前还款规则不同，工具不能承诺绝对准确。
2. 违约金、提前还款申请周期、扣款日期等应让用户手动输入。
3. 利率重定价规则较复杂，V1 不建议做太深。
4. 组合贷提前还款规则各地差异较大，V1 可以先默认优先还商贷。
5. 金额计算要避免浮点数误差。
6. 页面不要一次性展示所有字段，否则会失去“极简工具”的优势。

## 19. 产品总结

本产品的核心竞争点不是简单计算月供，而是帮助用户做房贷决策。

核心价值：

1. 清楚知道当前房贷成本；
2. 清楚知道提前还款能省多少钱；
3. 清楚比较“缩短年限”和“减少月供”；
4. 清楚看到利率变化对月供和总利息的影响；
5. 清楚管理商贷、公积金贷、组合贷的还款结构。

最终产品应保持一个原则：

```text
复杂计算交给系统，页面展示保持简单。
```
