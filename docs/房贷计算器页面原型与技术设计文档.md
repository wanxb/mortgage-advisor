# 房贷计算器页面原型与技术设计文档

## 1. 文档目标

本文档承接《房贷计算器产品需求文档 PRD》，用于指导前端页面设计、组件拆分、计算引擎开发和第一版工程实现。

目标是把产品需求转化为可开发的结构：

1. 页面如何布局；
2. 用户如何操作；
3. 前端组件如何拆分；
4. 计算引擎如何设计；
5. 各模块之间如何传递数据；
6. V1 第一版如何落地。

---

## 2. 产品形态

### 2.1 页面类型

V1 采用单页工具型页面，不做复杂路由。

页面路径建议：

```text
/mortgage
```

或者如果是独立工具站：

```text
/
```

### 2.2 页面整体原则

1. 页面只保留一个主流程；
2. 输入在上，结果在中，详细功能在下；
3. 高级设置默认收起；
4. 计算结果实时刷新；
5. 不强制用户点击多个确认按钮；
6. 表格信息默认折叠，避免视觉压力；
7. 移动端优先保证输入和结果卡片体验。

## 7.4 等额本息计算

```ts
function calculateEqualPaymentPlan(input: LoanInput): LoanPlan {
  const principal = yuanToCent(input.amount);
  const monthlyRate = input.annualRate / 100 / 12;
  const periods = input.years * 12;

  let monthlyPayment: number;

  if (monthlyRate === 0) {
    monthlyPayment = principal / periods;
  } else {
    monthlyPayment = principal * monthlyRate * Math.pow(1 + monthlyRate, periods) /
      (Math.pow(1 + monthlyRate, periods) - 1);
  }

  const schedule: PaymentScheduleItem[] = [];
  let remainingPrincipal = principal;
  let totalPaidPrincipal = 0;
  let totalPaidInterest = 0;

  for (let i = 1; i <= periods; i++) {
    const interest = remainingPrincipal * monthlyRate;
    let currentPrincipal = monthlyPayment - interest;

    if (i === periods) {
      currentPrincipal = remainingPrincipal;
      monthlyPayment = currentPrincipal + interest;
    }

    remainingPrincipal -= currentPrincipal;
    totalPaidPrincipal += currentPrincipal;
    totalPaidInterest += interest;

    schedule.push({
      period: i,
      date: addMonths(input.firstPaymentDate, i - 1),
      payment: monthlyPayment,
      principal: currentPrincipal,
      interest,
      remainingPrincipal: Math.max(0, remainingPrincipal),
      totalPaidPrincipal,
      totalPaidInterest,
    });
  }

  return buildLoanPlan(input, schedule);
}
```

说明：

1. 实际代码中建议使用 decimal.js 或 big.js；
2. 内部金额建议使用“分”或高精度 Decimal；
3. 最后一期需要校正本金，避免剩余本金出现小数误差。

```ts
function calculateEqualPrincipalPlan(input: LoanInput): LoanPlan {
  const principal = yuanToCent(input.amount);
  const monthlyRate = input.annualRate / 100 / 12;
  const periods = input.years * 12;
  const monthlyPrincipal = principal / periods;

  const schedule: PaymentScheduleItem[] = [];

  let totalPaidPrincipal = 0;
  let totalPaidInterest = 0;

  for (let i = 1; i <= periods; i++) {
    const interest = remainingPrincipal * monthlyRate;
    let currentPrincipal = monthlyPrincipal;

    if (i === periods) {
```

## 7.6 组合贷计算

```ts
function calculateCombinedLoanPlan(input: LoanInput): LoanPlan {
  const commercialPlan = calculateSingleSubLoanPlan({
    ...input,
    loanType: 'commercial',
    amount: input.commercial.amount,
    years: input.commercial.years,
    annualRate: input.commercial.annualRate,
  });

  const fundPlan = calculateSingleSubLoanPlan({
    ...input,
    loanType: 'fund',
    amount: input.fund.amount,
    years: input.fund.years,
    annualRate: input.fund.annualRate,
  });

  const maxPeriods = Math.max(
    commercialPlan.schedule.length,
    fundPlan.schedule.length
  );

  const mergedSchedule: PaymentScheduleItem[] = [];

  for (let i = 0; i < maxPeriods; i++) {
    const c = commercialPlan.schedule[i];
    const f = fundPlan.schedule[i];

    mergedSchedule.push({
      period: i + 1,
      date: c?.date || f?.date,
      payment: (c?.payment || 0) + (f?.payment || 0),
      principal: (c?.principal || 0) + (f?.principal || 0),
      interest: (c?.interest || 0) + (f?.interest || 0),
      remainingPrincipal: (c?.remainingPrincipal || 0) + (f?.remainingPrincipal || 0),
      totalPaidPrincipal: (c?.totalPaidPrincipal || 0) + (f?.totalPaidPrincipal || 0),
      totalPaidInterest: (c?.totalPaidInterest || 0) + (f?.totalPaidInterest || 0),
      commercial: c,
      fund: f,
    });
  }

  return buildLoanPlan(input, mergedSchedule);
}
```

## 7.7 年度汇总计算

```ts
function buildAnnualSummary(schedule: PaymentScheduleItem[]): AnnualSummaryItem[] {
  const yearMap = new Map<number, PaymentScheduleItem[]>();

  schedule.forEach(item => {
    const year = getYear(item.date);
    const list = yearMap.get(year) || [];
    list.push(item);
    yearMap.set(year, list);
  });

  return Array.from(yearMap.entries()).map(([year, months]) => {
    const totalPayment = sum(months.map(x => x.payment));
    const totalPrincipal = sum(months.map(x => x.principal));
    const totalInterest = sum(months.map(x => x.interest));
    const endRemainingPrincipal = months[months.length - 1].remainingPrincipal;

    return {
      year,
      totalPayment,
      totalPrincipal,
      totalInterest,
      endRemainingPrincipal,
      months,
    };
  });
}
```

```ts
  const node = findPrepaymentNode(originalPlan.schedule, prepaymentInput.date);
```

## 8.3 找到提前还款节点

```ts
function findPrepaymentNode(schedule: PaymentScheduleItem[], date: string) {
  return schedule.find(item => item.date >= date);
}
```

实际实现时建议：

1. 按月份比较；
2. 如果 includeCurrentMonthPayment = true，则提前还款发生在该期正常还款后；
3. 如果 includeCurrentMonthPayment = false，则提前还款发生在该期正常还款前；
4. V1 可以默认按“当期正常还款后提前还款”。

## 8.4 减少月供逻辑

```text
1. 找到提前还款节点；
2. 获取节点后的剩余本金；
3. 扣除提前还款金额；
4. 剩余期数保持不变；
5. 使用原贷款利率和剩余期数重新计算月供；
6. 生成新计划；
7. 与原剩余计划对比。
```

伪代码：

```ts
function calculateReducePaymentPlan(originalPlan, node, input) {
  const paidSchedule = getPaidSchedule(originalPlan, node);
  const remainingPeriods = originalPlan.summary.totalPeriods - node.period;
  const newPrincipal = node.remainingPrincipal - input.amount;

  const newRemainingPlan = calculatePlanByPrincipalPeriodsRate({
    principal: newPrincipal,
    periods: remainingPeriods,
    annualRate: originalPlan.input.annualRate,
    repaymentMethod: originalPlan.input.repaymentMethod,
    firstPaymentDate: nextMonth(node.date),
  });

  const adjustedSchedule = [...paidSchedule, ...newRemainingPlan.schedule];

  return buildPrepaymentResult(originalPlan, adjustedSchedule, input);
}
```

## 8.5 减少年限逻辑

```text
1. 找到提前还款节点；
2. 获取节点后的剩余本金；
3. 扣除提前还款金额；
4. 保持原月供尽量不变；
5. 用新本金、原月供、原利率反推剩余期数；
6. 生成新计划；
7. 与原剩余计划对比。
```

伪代码：

```ts
function calculateReduceTermPlan(originalPlan, node, input) {
  const paidSchedule = getPaidSchedule(originalPlan, node);
  const newPrincipal = node.remainingPrincipal - input.amount;
  const targetPayment = getCurrentMonthlyPayment(originalPlan, node);

  const newRemainingSchedule = calculateScheduleByTargetPayment({
    principal: newPrincipal,
    targetPayment,
    annualRate: originalPlan.input.annualRate,
    repaymentMethod: originalPlan.input.repaymentMethod,
    firstPaymentDate: nextMonth(node.date),
  });

  const adjustedSchedule = [...paidSchedule, ...newRemainingSchedule];

  return buildPrepaymentResult(originalPlan, adjustedSchedule, input);
}
```

## 8.6 缩短年限时反推期数

等额本息情况下：

```text
月供 M
本金 P
月利率 r
期数 n

M = P × r × (1 + r)^n / ((1 + r)^n - 1)
```

可反推：

```text
n = log(M / (M - P × r)) / log(1 + r)
```

注意：

1. 如果 M <= P × r，说明月供连利息都不够，需要提示无法缩短年限；
2. 期数需要向上取整；
3. 最后一期重新校正本金和月供。


```ts
function calculateRateAdjustedPlan(
  originalPlan: LoanPlan,
  input: RateAdjustInput
): RateAdjustResult {
  const node = findRateAdjustNode(originalPlan.schedule, input.effectiveDate);
  const paidSchedule = getPaidScheduleBeforeNode(originalPlan, node);

  const newRemainingPlan = calculatePlanByPrincipalPeriodsRate({
    principal: node.remainingPrincipal,
    periods: originalPlan.summary.totalPeriods - node.period,
    annualRate: input.newAnnualRate,
    repaymentMethod: originalPlan.input.repaymentMethod,
    firstPaymentDate: nextMonth(node.date),
  });

  const adjustedSchedule = [...paidSchedule, ...newRemainingPlan.schedule];

  return buildRateAdjustResult(originalPlan, adjustedSchedule, input);
}
```
